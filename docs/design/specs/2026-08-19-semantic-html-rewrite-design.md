# Semantic HTML rewrite (no div, class, or id)

## Purpose

Course submission requirement: the site's HTML must be "fully semantic" — no `<div>`, no `class` attribute, and no `id` attribute except where HTML has no alternative — while keeping the exact same visual design and improving SEO. This also serves as a genuine best-practices pass: real elements over generic containers, real attributes over styling hooks.

## Scope

- `index.html`
- `issue-001.html`
- `styles.css`
- `assets/js/speed-insights-init.js`'s neighboring inline scripts in both HTML files (sound toggle, comic-panel reveal, form submit handler)

Not touched: `assets/js/speed-insights.mjs` (vendored third-party bundle, regenerated by `npm run build`), `scripts/build.js`, `vercel.json`, `package.json`.

## Decisions

1. **`id` allowed only as real anchor targets.** Kept on the five sections in-page nav links jump to (`origin`, `issues`, `shoe`, `lore`, `join`) and nowhere else. The email field's label wraps its input instead of using `for`/`id`, so that pairing needs no `id`.
2. **Accent/highlighted text becomes `<mark>`**, restyled (`color` instead of the default yellow highlight) via a single element selector — replaces every `class="accent"` site-wide.
3. **Purely decorative, `aria-hidden` elements** (halftone dots, spore particles, corner registration marks) are removed from the DOM and recreated with CSS `::before`/`::after` and backgrounds on their semantic parent.
4. **CSS selectors** use element type, parent/child and sibling combinators, `:nth-of-type`/`:first-of-type`, and attribute selectors (`[href^="#"]`, `[open]`, `[aria-pressed]`) in place of classes. Some selectors will be positional/structural rather than named — accepted tradeoff for a graded snapshot, confirmed with the user.
5. **Sound toggle** button uses `aria-pressed="true"/"false"` (flipped by JS) instead of a `.on` class; CSS keys off `[aria-pressed="true"]`. This is a real accessible toggle-button pattern, not a styling hook.
6. **Comic panel reveal** (image → caption → word-by-word) moves from `IntersectionObserver` + `classList.toggle('in-view')` to CSS scroll-driven animation (`animation-timeline: view()`), with a `@supports` fallback so content simply appears (no animation) on browsers without support. Removes the observer script entirely.
7. **Form success message** toggled via the native `hidden` attribute (JS sets/clears it) instead of a `.submitted` class.
8. **SEO/semantic upgrades in passing:** `<time datetime="2026-04">APR 2026</time>` for issue dates, `<data value="001">#001</data>` for issue numbers.
9. **Progressive enhancement:** with JavaScript disabled, the sound toggle is inert but the rest of the site (nav, comic panels, forms, layout) works and looks correct.

## Out of scope / not changing

- Visual design, layout, copy, and images — pixel-identical to today.
- `README.md` — updated separately whenever project structure/setup changes (standing instruction, not tied to this rewrite).
- Any restructuring of section order or added/removed content.

## Risk accepted

Positional CSS selectors (e.g. `main > section:nth-of-type(2) article`) are more fragile to future markup reordering than class selectors. Acceptable for this graded, static snapshot.
